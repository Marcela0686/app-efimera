# Actividad 2.3: Ephemeral Environments (Ambientes Efímeros)

Este repositorio contiene un servidor web básico desarrollado en Node.js utilizando el framework Express. Su propósito principal es servir como código fuente para el despliegue de un **ambiente efímero** en la nube mediante Render.

Esta práctica forma parte de la asignatura Tendencias en Entornos de Desarrollo de Aplicaciones y Servicios, demostrando cómo levantar entornos de prueba aislados a partir de un repositorio de GitHub.

## 🛠️ Tecnologías utilizadas
* **Entorno de ejecución:** Node.js
* **Framework:** Express
* **Control de versiones:** Git & GitHub
* **Plataforma de despliegue (PaaS):** Render
